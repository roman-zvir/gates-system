## Як перевірити роботу:

### Крок 1: Запустіть Wokwi симулятор
1. Відкрийте https://wokwi.com/
2. Створіть новий проєкт ESP32
3. Скопіюйте код з `sketch.ino`
4. Запустіть симуляцію
5. Відкрийте Serial Monitor

### Крок 2: Перевірте підключення ESP32
В Serial Monitor ви повинні побачити:
```
=== ESP32 GATE ===
WiFi... OK!
MQTT connect as: ESP32-XXXX
✓ MQTT підключено!
✓ Підписано на gate/control
✓ Опубліковано статус online
```

### Крок 3: Запустіть React додаток
```bash
npm run dev
```

### Крок 4: Відкрийте браузер
1. Відкрийте консоль браузера (F12)
2. Перейдіть на вкладку Console
3. Ви повинні побачити:
```
Paho MQTT library loaded
Creating MQTT client with ID: webClient_XXXXXXXX
Підключено до MQTT брокера
Підписано на gate/status
```

### Крок 5: Натисніть кнопку "ВІДКРИТИ ВОРОТА"

**В консолі браузера:**
```
✅ Відправлено команду "open" на топік gate/control
```

**В Serial Monitor (Wokwi):**
```
>>> [gate/control]: open
🚪 ВІДКРИВАЮ!
✅ ЗАКРИТО!
✓ Статус відправлено
```

**В консолі браузера (через 100-200ms):**
```
Отримано повідомлення: gate/status opened
```

**На екрані додатку:**
Статус має змінитись на "Ворота відкриті!" на 2 секунди.

## Якщо не працює:

### Проблема 1: React не підключається до MQTT
**Симптоми:** Статус "Помилка підключення"

**Рішення:**
1. Перевірте консоль браузера на помилки
2. Переконайтесь, що браузер підтримує WebSocket
3. Перевірте, чи не блокує firewall з'єднання
4. Спробуйте інший браузер

### Проблема 2: ESP32 не підключається до MQTT
**Симптоми:** В Serial Monitor "✗ Помилка підключення, rc=X"

**Коди помилок:**
- `-4`: Timeout - перевірте інтернет з'єднання
- `-2`: Connect failed - брокер недоступний
- `5`: Unauthorized - проблема з авторизацією

**Рішення:**
1. Перевірте WiFi підключення в Wokwi
2. Спробуйте перезапустити симуляцію
3. Перевірте Serial Monitor на помилки

### Проблема 3: ESP32 не отримує команду
**Симптоми:** В Serial Monitor немає `>>> [gate/control]: open`

**Рішення:**
1. Переконайтесь, що ESP32 підключено до MQTT (є повідомлення "✓ MQTT підключено!")
2. Переконайтесь, що підписка успішна ("✓ Підписано на gate/control")
3. Перевірте, чи React відправляє команду (дивіться консоль браузера)
4. Спробуйте перезапустити обидві сторони

### Проблема 4: React не отримує статус від ESP32
**Симптоми:** Статус не змінюється на "Ворота відкриті!"

**Рішення:**
1. Перевірте, чи ESP32 публікує статус (в Serial Monitor: "✓ Статус відправлено")
2. Перевірте, чи React підписаний на `gate/status` (консоль: "Підписано на gate/status")
3. Перевірте консоль браузера на отримані повідомлення

## Тестування MQTT вручну

Ви можете протестувати MQTT з'єднання за допомогою онлайн клієнта:
https://www.hivemq.com/demos/websocket-client/

**Налаштування:**
- Host: `broker.emqx.io`
- Port: `8084`
- Protocol: `wss://`
- Client ID: `test_client_123`

**Підписка:**
- Topic: `gate/status`

**Публікація:**
- Topic: `gate/control`
- Message: `open`

Якщо ви опублікуєте "open" через цей клієнт, ESP32 повинен відреагувати!
